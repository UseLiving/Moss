# Moss

A cozy pixel farming game with a crypto twist. Farm glowing mushrooms, mine hash crystals in the Gloamwood, trade on the Exchange and stake $MOSS in the Root Vault.

**Play:** open `index.html` in a browser, or deploy this folder to GitHub Pages, Vercel or Netlify. No build step.

## Features

- Three areas: your farm, Capstone Village and the Gloamwood
- Hoe, watering can, scythe and pickaxe on a 10-slot hotbar, with energy
- Crops that grow overnight when watered, rain days, day and night
- Shipping bin that pays the nightly closing price, plus a live-moving Exchange with candlestick charts
- Root Vault staking, shop upgrades, quest board, 11 story goals
- Five villagers with friendship and gifts
- Synthesized music and sound effects, phone controls, saves in the browser
- Wallet connect (Solana, Wallet Standard) unlocks a golden cap

## The $MOSS flywheel

`flywheel.html` lays out how the in-game loop and the token loop feed each other, with a season simulator. It's also reachable from the game's title screen.

$MOSS is an in-game coin today. Nothing in the game touches the blockchain.

## Controls

| Action | Desktop | Phone |
|---|---|---|
| Walk | WASD / arrows | Arrow pad |
| Use tool or spores | Space | Use |
| Talk, harvest, open | E | Talk |
| Hotbar | 1–0, Q/R, wheel | Tap a slot |
| Eat | F | Bag |
| Bag / Quests / Pause | I / J / Esc | Buttons |
